# Python Learning for self
Python 学习记录与基础代码练习仓库，包含数据类型、函数等基础语法示例。

## 目录
- `DataType/`：Python 基础数据类型示例
- `Function_Learning/`：函数定义、参数传递等用法练习
- `.gitignore`：Git 忽略文件配置

## 环境与安装
### 依赖
- Python 3.8+
- Poetry

### 安装步骤
1. 克隆仓库
```bash
git clone https://github.com/awei-Guo/Python-Learning.git
```
2. 安装依赖
```
cd Python-Learning
poetry install
```
## 运行函数练习示例：
```bash
cd Function_Learning
poetry shell
python ./tests/Function_test.py
exit
```
